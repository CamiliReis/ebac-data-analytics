# Projeto Calculadora

## 📌 Descrição
Projeto desenvolvido como prática de Git e GitHub.

---

## ▶️ Como executar o script .sh

No terminal Linux:

bash calculadora.sh

---

## ▶️ Como executar o script .py

python3 calculadora.py

---

## 🧠 Explicação

O projeto consiste em uma calculadora simples que realiza:

- Soma
- Subtração
- Multiplicação
- Divisão

O script em Shell utiliza estruturas como `read` e `case` para interação com o usuário.

O script em Python utiliza entrada de dados e operações matemáticas básicas.
