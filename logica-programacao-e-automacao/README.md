## Lógica de Programação e Automação de Tarefas

Este módulo reúne fundamentos técnicos de lógica de programação e automação
de tarefas, aplicados em ambiente Linux, utilizando Python, Shell Script e Git.

O foco está no desenvolvimento de código estruturado, no uso de boas práticas
e na automação da execução de programas, conceitos essenciais para rotinas
de dados e ambientes produtivos.

---

## Python – Fundamentos de Lógica e Estruturas de Dados

**Competência:**  
Desenvolvimento de programas básicos em Python com foco em clareza,
organização do código e uso de estruturas de dados.

**Tópicos abordados:**
- Uso da função `print` para saída de dados
- Documentação de código com comentários e boas práticas
- Operadores aritméticos, relacionais e lógicos
- Estruturas de dados: listas, tuplas e dicionários
- Análise de uso e eficiência das estruturas de dados

Ferramenta utilizada: **Google Colab**.

---

## Linux (Unix) – Sistema de Arquivos e Automação

**Competência:**  
Utilização do Linux para navegação no sistema de arquivos, gerenciamento
de permissões e automação de execução de scripts.

**Tópicos abordados:**
- Comandos básicos de navegação (`pwd`, `ls`, `cd`)
- Criação e organização de diretórios e arquivos (`mkdir`, `touch`)
- Manipulação de arquivos (`cp`, `mv`, `rm`, `cat`, `head`, `tail`)
- Gerenciamento de permissões e propriedades (`chmod`, `chown`)
- Execução de scripts Python via Shell Script

Este módulo inclui um exercício prático de automação, no qual um script
Shell é utilizado para orquestrar a execução de um programa em Python
em ambiente Linux.

---

## Git e GitHub – Controle de Versão

**Competência:**  
Versionamento de código e organização de projetos utilizando Git e GitHub.

**Tópicos abordados:**
- Conceitos fundamentais de controle de versão
- Configuração inicial do Git
- Criação e gerenciamento de repositórios locais e remotos
- Fluxo básico de trabalho com branches
- Resolução de conflitos por meio de pull requests

---

## Aplicação Prática

Os conceitos deste módulo formam a base para:
- Automação de tarefas repetitivas
- Execução de scripts sem intervenção manual
- Padronização de processos
- Estruturação de pipelines simples de dados
- Organização de projetos em ambientes Linux
